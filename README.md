# Portofoliu — Iulian Dițu

Site personal static, responsive, construit cu HTML, CSS și JavaScript.

## Structură

- `index.html` — pagina principală
- `assets/css` — stilurile site-ului
- `assets/js` — interacțiunile globale
- `assets/images` — logo, fotografie și favicon
- `assets/documents` — CV-ul descărcabil
- `projects` — aplicațiile demonstrative
